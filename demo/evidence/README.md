# 实际运行证据

2026-11-19 在 Docker 中运行 Codex CLI 0.169.1，通过 Chromium 操作工作台。三轮任务均返回完成状态。下载产物后，单独运行 CSV 汇总工具核对结果，并重启容器检查持久化。

| 验收 | 结果与证据 |
| --- | --- |
| 多会话 | CSV 会话执行期间，会议会话可接收上传并排队。关闭并重新打开页面后恢复 CSV 会话，仍可切换到会议会话。见[排队截图](queued.png)。 |
| 代码及续聊 | 首轮输出 `Supplies,12.75` 和 `Travel,30.00`。同一会话追加 `--total` 后输出 `TOTAL,42.75`，默认输出保持原样。见[截图](code.png)、[CLI 记录](code-runs.json)及[下载的脚本](summarize.py)。 |
| 材料整理 | 上传模拟会议纪要后生成报告，包含两项明确日期和两项待定事项。见[截图](report.png)、[CLI 记录](report-runs.json)及[下载的报告](report.md)。 |
| 错误与重试 | 在独立容器中省略模型配置，页面显示配置错误。点击重试在原会话创建新运行，配置仍缺失时第二次运行同样失败。见[失败截图](failure.png)。 |
| 服务重启 | 重启 Docker 服务后，两个会话、三轮执行结果及两件产物仍可读取。 |
